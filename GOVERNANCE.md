# 🏛️ Marco de Gobernanza — Chatter_Companion

Este AddOn opera bajo las directrices del **Estándar L9 de Project Jaina**:
1. **Soberanía y Código Abierto:** Todo desarrollo debe ser libre y accesible para la comunidad.
2. **Aislamiento de Recursos:** Ningún proceso de diálogo debe saturar el canal de chat principal del juego (`SAY`, `YELL`, `GENERAL`). Los diálogos de IA ocurren por canales dedicados y susurros.
3. **Eficiencia en Roster:** El número de entradas en memoria está limitado para prevenir fragmentación de memoria en sesiones largas.
