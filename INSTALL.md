# 🚀 Guía de Instalación — Chatter_Companion

## Requisitos Previos
* Cliente World of Warcraft 3.3.5a (Build 12340).
* Servidor JainaCore con el módulo `mod-llm-chatter` habilitado.

## Instrucciones
1. Clona o copia la carpeta `Chatter_Companion` dentro de:
   ```text
   Interface\AddOns\Chatter_Companion\
   ```
2. Inicia sesión en el juego y verifica que el AddOn figure como activado en el menú de AddOns.
3. Utiliza el comando `/chatter` o susurra a un bot compatible para iniciar la conversación.
